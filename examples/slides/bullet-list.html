A clear update

Keep every point connected to the main idea.

  • Start with one outcome the audience can repeat.
    • State the decision in plain language.
    • Include background only when it changes the interpretation.
  • Show evidence that answers the main question.
    • Name the source and reporting period.
  • Compare options on the same basis.
    • Use shared units and the same time span.
    • Call out the one difference that matters.
  • Put the result in context.
  • Keep qualifications beside the claim they affect.
    • Move supporting methodology into a footnote when it does not fit in the main point.
  • Close with one concrete next step.
